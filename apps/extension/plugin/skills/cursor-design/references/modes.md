# Surface modes

Pick **one mode per frame** (or per page of frames) before designing. Mode sets ambition, density, and what “good” means.

| Mode | Surfaces | Ambition | Default craft |
|---|---|---|---|
| **persuade** | Landing, promo, hero, pricing story | Bold, distinctive POV | Full-bleed media, expressive type, one memorable moment |
| **operate** | App screens, dashboards, settings, forms | Precision + restraint | Known patterns, dense-but-clear, tokens over decoration |
| **read** | Docs, empty states, long-form in-product | Legibility | Quiet chrome, strong hierarchy, short line lengths |
| **experience** | Immersive / cinematic / onboarding moments | Atmosphere | Image/video fills, glass, overlay copy, motion via transform only |

## Rules

- The **brief wins**. If the user pinned an era, palette, or brand, follow it even when it conflicts with a ban.
- **Refinement preserves; redesign replaces.** Don’t half-repaint an existing look unless asked to redesign.
- Marketing frames (`persuade`) may use Committed / Full palette color. Product frames (`operate`) default to **Restrained**: tinted neutrals + one accent ≤ ~10% of the surface.
- Dark vs light is a choice from context (ambient light, mood), not a cool-tools default.

# Explore (divergence)

Use when the user asks for options, directions, or “what are the alternatives?” — not on every task.

## Protocol

1. **Scope** to one piece (a card, a hero, a chart block) — not the whole product.
2. Propose **3 variants** (max 5). Each needs a **name** and a **named axis** (layout, density, personality, hierarchy). Names like Quiet / Dense / Editorial — never Option A/B/C.
3. If two variants would only differ by accent color, merge them; replace with a real structural alternative.
4. Build each as a **top-level frame** on the same page (or adjacent x positions), sharing the same tokens. Realistic copy — no lorem.
5. `design_screenshot` each frame (or the page’s key frames). Present a short table: Variant · Axis · Wins when · Costs.
6. **Stop** — the user picks. Then delete losing frames (or keep if asked) and refine the winner.

## Axes examples

| Axis | Quiet | Dense | Editorial |
|---|---|---|---|
| Layout | Single column, airy | Split / rail, compact | Asymmetric, large type |
| Density | Hug content, large gaps | Fill, tight gaps | Hero type, sparse chrome |
| Data | KPI + sparkline | Table-like ranks | One big number |

Variants must feel shippable in *this* product’s tokens — divergence of structure, not a random new brand.
